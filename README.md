# SportViva
A SportViva é um site educativo que apresenta modalidades esportivas e incentiva uma vida ativa. Na página inicial, o visitante conhece corrida, vôlei e musculação. Cada modalidade tem uma página própria, com explicações, benefícios, locais para praticar e dicas para começar. Com visual moderno e navegação simples, o site aproxima todos do esporte.
